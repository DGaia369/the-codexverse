## Purpose

This Build Room exists to faithfully implement Pathway Two™: ReMEMBER™ according to the approved architecture.

The philosophical work is considered sufficiently mature for implementation.

Discovery is no longer the primary activity.

Implementation is.

If new constitutional insight emerges during implementation, it will be captured, preserved, and ruled upon separately. The build itself does not pause unless that new insight materially changes approved architecture.

## The Build Question

Every implementation decision begins with one question.

> **How do we faithfully build what Pathway Two™ already is?**

We are not inventing the pathway.

We are expressing it.

## The Four Build Questions

Every proposed feature, screen, prompt, Recognition Record™, database table, email, interaction, migration, API, document, or implementation decision must successfully answer these four questions before it is approved.

### 1. Does this faithfully express the approved architecture?

Implementation must never quietly reinterpret architecture.

If implementation requires a new architectural decision, implementation stops until the Founder rules.

### 2. Is this the simplest implementation that preserves that architecture?

Complexity requires justification.

Simplicity is preferred whenever architectural integrity remains unchanged.

### 3. Does this preserve continuity for future builders?

Every decision should reduce reconstruction.

Future contributors should inherit understanding rather than rediscover it.

The repository exists to preserve continuity.

### 4. Will it reduce the attention required to continue tomorrow?

The builder's attention is a finite resource.

Implementation should progressively transfer continuity into the repository so human attention becomes available for judgment rather than reconstruction.

If the answer to these four questions is yes...

**we build.**

Not excavate.
