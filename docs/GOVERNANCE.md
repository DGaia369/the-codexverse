# Constitutional Conflict Rule

If two repository documents appear to conflict:

1. Preserve the higher governing layer.
2. Do not silently reinterpret either document.
3. Identify the conflicting files.
4. Surface the discrepancy.
5. Await a constitutional ruling from Diana Francis.
6. Record the ruling in History.
