# AI Collaboration Standard

**Status:** Governing standard

Before working, every AI collaborator must read:

1. `docs/GOVERNANCE.md`
2. `docs/canon/`
3. `docs/standards/`
4. `docs/architecture/`
5. relevant `docs/history/`

AI must distinguish canon, proposal, current implementation, verified deployment, historical context, and unresolved questions.

AI must not infer approval from silence, call proposed language canon, call local code live, rewrite participant-authored language, introduce new philosophy while implementing locked architecture, use memory as the sole authority when repository documents exist, or silently resolve contradictions.

When conflict appears:

1. quote the conflicting statements
2. identify their file locations
3. identify their statuses and dates
4. preserve the higher governing layer
5. ask Diana for a ruling
6. record the ruling after confirmation
